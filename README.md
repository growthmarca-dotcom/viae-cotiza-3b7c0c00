# ViaE Quotations Hub

Quiero crear una aplicación web responsive llamada "ViaE Cotizaciones".

El objetivo es que un agente de viajes pueda crear cotizaciones profesionales para clientes y compartirlas mediante un enlace único.

Diseña una interfaz moderna, elegante y minimalista, inspirada en Booking.com y Airbnb, utilizando colores blanco, verde oscuro, beige y detalles dorados.

Debe tener autenticación mediante correo y contraseña.

Luego del inicio de sesión mostrar un Dashboard con las siguientes opciones:

- Nueva cotización

- Cotizaciones

- Clientes

- Configuración

En el Dashboard mostrar estadísticas:

- Cotizaciones creadas

- Cotizaciones aceptadas

- Cotizaciones pendientes

- Cotizaciones vencidas

Crear toda la estructura de navegación y dejar listas las páginas aunque todavía no tengan funcionalidad.

Utilizar Supabase como base de datos.

El código debe ser limpio, escalable y preparado para agregar nuevas funciones en el futuro.
